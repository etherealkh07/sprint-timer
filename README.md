# Sprint — Question Practice Timer

A free, offline practice timer built for **CAT** and **SNAP** exam preparation. Set a per-question timer for quick practice, or switch on Test Mode to simulate full sectional mock tests with automatic section transitions — plus a Weekly Goals tracker to keep your prep on schedule.

No installation, no login, no ads, no internet required after the page loads. Just open it and start practicing.

## Features

- **Manual Practice Mode** — set any number of questions and any time per question (seconds or minutes), then start a simple countdown session.
- **Test Mode (CAT / SNAP)** — pick a real exam pattern and the timer automatically runs each section (VARC, DILR, QA, etc.) with the correct number of questions and section time limits, moving on to the next section when time is up.
- **Question end beep toggle** — turn the per-question countdown beep on or off. Turning it off doesn't change how the timer runs — questions and sections still advance on the same schedule, only the sound is muted.
- **Section time in the main clock** — in Test Mode with the beep off, the main clock switches to show the current section's remaining time (with seconds) instead of the per-question timer.
- **Weekly Goals tracker** — add the topics you want to finish, set your own deadline, check goals off as you complete them, and see a live countdown to your deadline. Close out a week to save it to a history log you can look back on.
- **Light / dark mode** with a toggle, remembered across visits.
- **Accurate timing** even if you switch tabs or apps — the timer is based on real elapsed time, not a simple tick counter.
- **Runs entirely in your browser** — all your settings, goals, and history are saved locally on your device (nothing is sent anywhere).

## How to use

1. Open the page (see the live link in the repo's About section, or open `index.html` directly in any browser).
2. **For quick practice:** set the number of questions and time per question, then hit **Start**.
3. **For a full mock test:** turn on **Test Mode**, pick **CAT** or **SNAP**, set your per-question time, and hit **Start**. The timer will run through every section automatically.
4. **For weekly planning:** scroll to the **Weekly Goals** card, set a deadline, add your topics, and check them off as you go. Click **Finish this week** when you're done to archive it and start fresh.

## Tech

Just a single self-contained HTML file — no build step, no dependencies, no server needed. Works on desktop and mobile.
